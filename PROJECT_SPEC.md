# Project Specification

## Project
Manufacturing Data Quality & Analytics Governance Platform

## Fictional business
PackRight Manufacturing — fictional packaging manufacturer.

## Primary portfolio objective
Demonstrate practical ability across:

- Python
- SQL
- ETL/data pipelines
- Data analysis
- Power BI
- Data quality
- Master data
- Data governance
- Metadata
- Data lineage
- Business glossary
- APIs
- GenAI/process automation
- Testing

## Core business questions

### Operations
- Which facilities produce the most?
- Which product categories drive volume?
- How are production and inventory changing?
- Which facilities have operational anomalies?

### Logistics
- What is the on-time delivery rate?
- Where are delays concentrated?
- Which customers/orders experience repeated delays?

### Data quality
- Which source has the weakest data quality?
- Which validation rules fail most frequently?
- Which facilities have the most exceptions?
- Are critical data elements complete and valid?

### Governance
- Which critical fields are documented?
- Which fields have owners?
- Can important fields be traced from source to reporting?
- Which KPIs have documented definitions?
